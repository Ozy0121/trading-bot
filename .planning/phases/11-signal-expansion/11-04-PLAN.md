<objective>
Fix the structural bug that prevents momentum-only predictions from ever being produced.

Purpose: The dual-path architecture (D-09) is broken because `_predict_momentum()` is called
AFTER the MR primary-signal gate (`if primary_count < 2: return None` at line 635). A pure
momentum breakout stock exits `predict()` before the momentum path runs. Additionally, the
merge logic at line 851 (`if momentum_result and not mr_result`) is dead code because
`mr_result` is always a truthy Prediction dataclass at that point. This gap closure fixes
control flow so both paths can fire independently.

Output: Fixed prediction.py with working dual-path routing, plus tests proving momentum-only
predictions work.
</objective>
