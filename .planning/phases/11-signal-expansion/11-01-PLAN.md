2. **`_detect_stoch_rsi(df: pd.DataFrame) -> PatternResult`** (per D-04):
   - Adapt from `agents/quant_analyst.py:_calc_stochastic_rsi()` — compute RSI(14), then normalize RSI over 14-period rolling window: `stoch = (rsi - rsi_min) / (rsi_max - rsi_min)`
   - Detection threshold: stoch_rsi < 0.10
   - Scoring curve: < 0.05 -> 10.0, < 0.10 -> 8.0 scaled linearly, < 0.20 -> 4.0 scaled, else 0.0
   - Min bars: 28 (RSI 14-period + stoch 14-period window)
   - Return `PatternResult("stoch_rsi", detected, score, "momentum", {"stoch_rsi_value": round(stoch_val, 4)})`

3. **`_detect_mfi(df: pd.DataFrame, period: int = 14) -> PatternResult`** (per D-05):
   - Adapt from `agents/quant_analyst.py:_calc_mfi()` — typical_price = (high+low+close)/3, money_flow = typical_price * volume, separate positive/negative flows, MFI = 100 - 100/(1 + positive_sum/negative_sum)
   - Detection threshold: MFI < 20
   - Scoring: < 10 -> 10.0, < 15 -> 8.0, < 20 -> 6.0, else 0.0
   - Min bars: period + 1
   - Return `PatternResult("mfi", detected, score, "volume", {"mfi_value": round(mfi_val, 2)})`

4. **`_detect_vwap(df: pd.DataFrame) -> PatternResult`** (per D-06):
   - Adapt from `agents/quant_analyst.py:_calc_vwap()` — cumulative (typical_price * volume).cumsum() / volume.cumsum()
   - Detection: current close < vwap value (price below average cost)
   - Score: based on percent below VWAP — >3% below -> 8.0, >1% -> 5.0, at VWAP -> 2.0
   - Min bars: 10
   - Details: `{"vwap_value": ..., "pct_below_vwap": ..., "note": "multi-day VWAP (not intraday reset)"}`
   - Return `PatternResult("vwap", detected, score, "volume", details)`

5. **`_detect_keltner_lower(df: pd.DataFrame) -> PatternResult`** (per D-07):
   - Use existing `indicators.py:keltner_channels(df)` which returns `(upper, mid, lower)` as pd.Series
   - Detection: current close <= lower Keltner channel value
   - Score: how far below lower channel — at channel -> 6.0, 1% below -> 8.0, 2%+ below -> 10.0
   - Min bars: 20 (EMA period for Keltner)
   - Return `PatternResult("keltner_lower", detected, score, "volatility", {"keltner_lower": ..., "price": ...})`

6. **`_detect_macd_divergence(df: pd.DataFrame, lookback: int = 20) -> PatternResult`** (per D-08):
   - Use `indicators.py:macd(closes)` -> returns (macd_line, signal_line, histogram)
   - Find two local price lows in last `lookback` bars (local low = bar whose low < surrounding 2 bars)
   - Require at least 5 bars between the two reference lows (per RESEARCH.md Pitfall 3)
   - Require price second low at least 1% below first low (filter noise)
   - Bullish divergence: price made lower low BUT histogram made higher low
   - Score: 8.0 if detected (strong reversal signal), 0.0 otherwise
   - Min bars: lookback + 30 (MACD needs 26-period EMA warmup)
   - Return `PatternResult("macd_divergence", detected, score, "momentum", {"divergence_type": "bullish", "price_low_1": ..., "price_low_2": ..., "hist_low_1": ..., "hist_low_2": ...})`

7. **`_find_swing_lows(df: pd.DataFrame, lookback: int = 20, n: int = 2) -> list[float]`** (per D-17):
   - A local low = bar whose `low` is lower than `n` bars before AND `n` bars after
   - Iterate from index `n` to `len(lows) - n`, check all neighbors
   - Return sorted list of float prices (most recent `lookback` swing lows)

8. **`_find_swing_highs(df: pd.DataFrame, lookback: int = 20, n: int = 2) -> list[float]`** (per D-17):
   - Mirror of `_find_swing_lows` using `high` column
   - Return sorted list of float prices

9. **`_detect_support_level(df: pd.DataFrame) -> PatternResult`** (per D-19):
   - Call `_find_swing_lows(df)` to get support levels
   - Detection: current close within 1.5% of any support level
   - Score: within 0.5% -> 8.0, within 1.0% -> 6.0, within 1.5% -> 4.0
   - Min bars: 25 (per RESEARCH.md Pitfall 7)
   - Return `PatternResult("support_level", detected, score, "structure", {"nearest_support": ..., "distance_pct": ...})`
