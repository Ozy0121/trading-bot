## Grade Threshold Logic (JS)

Threshold source: `d.conviction_threshold` from SSE state snapshot (NOT hardcoded to 5.8).

```javascript
function scoreToGrade(score, threshold) {
  if (score >= threshold + 2.2) return { letter: 'A', cls: 'grade-a' };
  if (score >= threshold)       return { letter: 'B', cls: 'grade-b' };
  if (score >= threshold - 1.8) return { letter: 'C', cls: 'grade-c' };
  if (score >= threshold - 3.3) return { letter: 'D', cls: 'grade-d' };
  return { letter: 'F', cls: 'grade-f' };
}
```

Source: CONTEXT.md D-06/D-07 (locked decisions).

## Grade Application Scope (SCORE-01 / D-02)

Grades appear wherever a conviction score is rendered. Apply the grade pill to these locations:

| Location | Element | Grade pill placement |
|----------|---------|----------------------|
| Watchlist table | Score `<td>` | Replace raw `r.score.toFixed(1)` with `gradeCell(r, threshold)` |
| Trade log entries | Conviction score display (if rendered) | Inline grade pill before or after numeric score |
| Sentiment section | Conviction readout for active symbol (if rendered) | Inline grade pill |

If a location currently does not render a conviction score, do NOT add one — only apply grades where scores already appear. Do not add new score displays to locations that don't currently show them.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Tooltip header | `Conviction: {LETTER} ({score}/10)` — e.g. "Conviction: A (8.2/10)" |
| Tooltip footer: strategies fired | `Strategy: {Name} + {Name}` — title-cased, joined with " + " |
| Tooltip footer: no strategies fired | `Strategy: None fired` |
| Grade pill format | `{LETTER} {score}` — e.g. "A 8.2" (no brackets, no slash, one decimal) |

No empty state copy required — the watchlist table always shows a score (0.0 minimum) when a row is present. The watchlist table itself has its own empty state ("No candidates yet") which is unchanged.

No destructive actions in this phase.

No error state copy required — grade computation is a pure JS function with no network calls. If `r.conviction` is missing or malformed, the pill defaults to `scoreToGrade(0, threshold)` which renders as grade F with score 0.0.
