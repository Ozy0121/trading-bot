    Create `sentiment_cache.py` as a new top-level module following the existing module pattern (docstring, imports, logger, module-level constants).

    **Imports:** `time`, `datetime` (datetime, timezone, timedelta), `date` from datetime, `requests`, `xml.etree.ElementTree as ET`, `config`, `get_logger` from logger_setup. Conditionally import alpaca NewsClient (try/except to handle missing).

    **Sentiment Cache (D-06, D-07, D-08):**
    - Module-level `_cache: dict[str, tuple[float, float]]` mapping symbol -> (timestamp, score)
    - `SENTIMENT_TTL = 1800` (30 minutes per D-08)
    - `get_sentiment_score(symbol: str) -> float`: Check cache TTL, return cached if fresh, else fetch and cache
    - `_fetch_sentiment(symbol: str) -> float`: Try `_fetch_alpaca_news()` first, fallback to `_fetch_yahoo_rss()`, score headlines with keyword counting
    - `_fetch_alpaca_news(symbol: str) -> list[str] | None`: Use `NewsClient(api_key=config.API_KEY, secret_key=config.SECRET_KEY)`, `NewsRequest(symbols=symbol, limit=10, start=3_days_ago)`, return list of headline strings. Wrap in try/except, return None on failure.
    - `_fetch_yahoo_rss(symbol: str) -> list[str] | None`: GET `https://feeds.finance.yahoo.com/rss/2.0/headline?s={symbol}&region=US&lang=en-US` with 8s timeout and User-Agent header. Parse XML with ET, extract title elements. Return None on failure.
    - Keyword lists per D-07 (from research Pattern 4):
      - `_BULLISH_KEYWORDS`: upgrade, upgrades, upgraded, outperform, overweight, price target raised, strong buy, buy rating, bullish, rally, beat, beats, record, surges, soars, jumps, initiates
      - `_BEARISH_KEYWORDS`: downgrade, downgrades, downgraded, underperform, underweight, price target cut, sell rating, bearish, falls, drops, plunges, misses, miss, warning, concern, decline
    - Scoring formula: `raw = (bull_count - bear_count) / total_headlines` mapped from [-1,+1] to [0,10] via `(raw + 1) / 2 * 10`

    **Earnings Penalty (D-09, D-10):**
    - Module-level `_earnings_cache: dict[str, tuple[date, date | None]]` mapping symbol -> (fetch_date, next_earnings_date)
    - `get_earnings_penalty(symbol: str) -> float`: Check if cached for today, else fetch via `yf.Ticker(symbol).calendar`. Return 0.0-2.0 penalty.
    - Penalty formula per research Pattern 6: 3 days = 0.5, 2 days = 1.0, 1 day = 1.5, 0 days = 2.0. Formula: `(3 - days_until) * 0.5 + 0.5` for days_until <= 3.
    - Guard against missing/empty calendar data (Pitfall 4): default to no penalty (0.0).

    **Logging:** Use `log = get_logger()` with prefix `[sentiment_cache]`. Log at DEBUG level for cache hits, INFO for API fetches, WARNING for API failures.

    **Thread safety (Open Question 1 from research):** Use a `threading.Lock` around the cache check+update in `get_sentiment_score()` to prevent duplicate fetches from parallel scan workers.
