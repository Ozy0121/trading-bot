    Rewrite `scanner.py` preserving the public interface (`scan()`, `best_buy()`, `get_watchlist()`, `fetch_bars_yf()`, `fetch_top_movers()`) but replacing the internals with multi-strategy conviction scoring.

    **Keep unchanged:**

    **Add new imports:**
    ```python
    from concurrent.futures import ThreadPoolExecutor, as_completed
    from datetime import datetime, timezone
    import yfinance as yf
    from strategies import REGISTRY
    from sentiment_cache import get_sentiment_score, get_earnings_penalty

    ```

    **New: `_fetch_sector_scores() -> dict[str, float]`** (per D-11, D-12, SCAN-02):
    - `SECTOR_ETFS = ["XLK","XLE","XLF","XLV","XLI","XLC","XLY","XLP","XLU","XLRE","XLB"]`
    - `SECTOR_ETF_MAP = {"Technology": "XLK", "Energy": "XLE", "Financial Services": "XLF", "Financials": "XLF", "Healthcare": "XLV", "Industrials": "XLI", "Communication Services": "XLC", "Consumer Cyclical": "XLY", "Consumer Defensive": "XLP", "Utilities": "XLU", "Real Estate": "XLRE", "Basic Materials": "XLB"}`
    - Use `yf.download(SECTOR_ETFS, period="5d", interval="1d", group_by="ticker", auto_adjust=True, progress=False)`
    - Compute 5-day % change per ETF, rank linearly: rank 0 -> score 10.0, rank N-1 -> score 0.0
    - Wrap in try/except, return `{etf: 5.0 for etf in SECTOR_ETFS}` on failure

    **New: `_sector_cache: dict[str, tuple[date, str]]`** (Open Question 3 from research):
    - Cache sector string per symbol per trading day to avoid re-fetching `yf.Ticker(sym).info`

    **New: `_get_stock_sector_score(symbol, etf_scores) -> float`**:
    - Look up symbol's sector via `yf.Ticker(symbol).info.get("sector", "")` (cached per day)
    - Map sector to ETF via `SECTOR_ETF_MAP`, return ETF's score from `etf_scores`
    - Default 5.0 if sector unknown

    **New: `_volume_ratio_to_score(vol_ratio: float) -> float`** (PRED-02):
    - Below 2x threshold: `min(5.0, (vol_ratio / 2.0) * 4)`
    - At/above 2x: `5 + min(5.0, (vol_ratio - 2.0) / 3.0 * 5.0)`
    - Always return `round(result, 2)`, clamped 0-10

    **Replace: `_score_symbol()` with `_score_symbol_multi(symbol, etf_scores, catalysts=None) -> dict | None`**:
    1. Fetch bars via `fetch_bars_yf(symbol)` — return None if insufficient data
    2. Run all strategies from `REGISTRY` against the symbol's DataFrame, collecting results. Pass `catalysts` kwarg to catalyst strategy.
    3. Compute technical sub-score: max `technical_score` from strategies that fired; if none fired, use max score * 0.5 (partial credit per research Pattern 3)
    4. Compute volume sub-score via `_volume_ratio_to_score()` using best `volume_ratio` from strategy results
    5. Get sentiment sub-score via `get_sentiment_score(symbol)` (from sentiment_cache.py)
    6. Get sector sub-score via `_get_stock_sector_score(symbol, etf_scores)`
    7. Compute composite: weighted average using `config.CONVICTION_WEIGHT_TECHNICAL` (0.40), `config.CONVICTION_WEIGHT_VOLUME` (0.20), `config.CONVICTION_WEIGHT_SENTIMENT` (0.20), `config.CONVICTION_WEIGHT_SECTOR` (0.20) per D-03
    8. Apply earnings penalty: `composite = max(0, composite - get_earnings_penalty(symbol))` per D-10
    9. Build conviction breakdown dict per D-05: `{"technical": X, "volume": X, "sentiment": X, "sector": X, "composite": X, "strategies_fired": [names], "earnings_penalty": X}`
    10. Return backward-compatible result dict: `{"symbol": symbol, "price": float, "signal": "BUY"/"HOLD", "raw_signal": str, "score": composite, "rsi": float, "volume_ratio": float, "bb_upper": float, "bb_lower": float, "macd_hist": float, "conviction": breakdown_dict, "df": df, "strategy": best_strategy_name}` — the `signal` field is "BUY" if any strategy fired and composite >= threshold, else "HOLD". Keep existing keys for backward compat (Pitfall 7: strip df before storing in state).

    **Replace: `scan()` function** (STRAT-06, SCAN-01, SCAN-05):
    ```python
    def scan(watchlist: list[str], catalysts: dict | None = None) -> list[dict]:
    ```
    1. Log scan start: `log.info("[scanner] Multi-strategy scan: %d symbols", len(watchlist))`
    2. Pre-fetch sector ETF scores once: `etf_scores = _fetch_sector_scores()`
    3. Use `ThreadPoolExecutor(max_workers=10)` per D-13 to run `_score_symbol_multi` in parallel for all symbols
    4. Collect results, skip None returns (failed fetches)
    5. Sort by `conviction["composite"]` descending
    6. Call `_log_scan_results(results)` for comprehensive logging per D-16
    7. Store in shared state (strip df first per Pitfall 7):
       ```python
       state_results = [{k: v for k, v in r.items() if k != "df"} for r in results]
       shared_state.update(
           scan_results=state_results,
           last_scan_time=datetime.now(timezone.utc).isoformat(),
           scan_conviction_scores={r["symbol"]: r["conviction"]["composite"] for r in results},
       )
       ```
    8. Return full results (with df, for bot's charting use)

    **Replace: `best_buy()` function** (PRED-04, PRED-05):
    ```python
    def best_buy(results: list[dict]) -> dict | None:
    ```
    1. Use `config.CONVICTION_THRESHOLD` (7.0) as gate per D-04
    2. Iterate results (already sorted descending)
    3. First result with `conviction["composite"] >= threshold`: log and return it
    4. For skipped candidates: log at INFO level with full breakdown per D-17:
       `"[scanner] Skipped %s (%.1f/10): technical=%.1f, volume=%.1f, sentiment=%.1f, sector=%.1f — composite below %.1f threshold"`
    5. Return None if no candidate meets threshold

    **New: `_log_scan_results(results)` function** (PRED-05, D-16):
    - Log at INFO: total candidates, top 5 with scores
    - For each result, log: symbol, composite score, strategies that fired, whether above threshold
    - Use `log_trade_event` from `logger_setup` for structured trade event logging where a candidate passes threshold

    **New: `get_watchlist()` update** (SCAN-03):
    - Change from `config.WATCHLIST` to `config.SWING_WATCHLIST`
    - Keep `fetch_top_movers()` call for `USE_TOP_MOVERS=true` mode
    - Combine: if USE_TOP_MOVERS, merge top movers with SWING_WATCHLIST (deduplicated)
