<objective>
Improve prediction engine v4 measured win rate from 51.2% toward 55%+ while maintaining 100+ signals. Three changes: (1) smart exit strategy in backtester so wins are measured at first up-close or RSI(2)>65 instead of fixed day-3 close, (2) relax consecutive down-day detection to use lower closes instead of lower-high+lower-low, (3) add volume spike confirmation as bonus scoring.

Purpose: The fixed day-3 exit measurement underestimates actual win rate because many mean-reversion bounces happen on day 1-2 then pull back by day 3. Smart exit captures these real wins. The other two changes increase signal quality and quantity.

Output: Updated backtester.py with smart exit, updated prediction.py with relaxed consec_down + volume filter, passing tests.
</objective>

<task type="auto">
  <name>Task 2: Relax consec_down detection + add volume spike bonus in prediction.py</name>
  <files>prediction.py, tests/test_prediction.py</files>
  <action>
Two changes to prediction.py:

**A. Relax consecutive down-day detection (line 208-235):**

Modify `_detect_consec_down()` to check consecutive lower CLOSES instead of lower-high AND lower-low:
- Change the inner loop condition from `h_cur < h_prev and l_cur < l_prev` to `close_cur < close_prev`
- Read close values: `c_cur = float(df["close"].iloc[i])` and `c_prev = float(df["close"].iloc[i - 1])`
- Keep the high/low variables for backward compatibility but use close comparison for detection
- Update the docstring to reflect "3 consecutive lower closes" instead of "lower high + lower low"
- This will generate MORE signals (lower closes is less restrictive), helping maintain 100+ signal count

**B. Add volume spike confirmation bonus:**

Add a new function `_detect_volume_spike(df: pd.DataFrame) -> PatternResult`:
- Compute 20-day average volume: `avg_vol = df["volume"].iloc[-21:-1].mean()`
- Current volume: `cur_vol = float(df["volume"].iloc[-1])`
- Volume ratio: `vol_ratio = cur_vol / avg_vol` if avg_vol > 0
- `detected = vol_ratio >= 1.5` (volume spike = 1.5x average)
- Scoring: ratio >= 2.5 -> score 10.0, ratio >= 2.0 -> 8.0, ratio >= 1.5 -> 6.0, ratio >= 1.2 -> 3.0, else 0.0
- Category: "volume", details: {"volume_ratio": round(vol_ratio, 2)}
- Return early with (False, 0.0) if len(df) < 22

Add volume spike to confirmation layer, NOT primary signals:
- Add `"volume_spike": 1.5` to `CONFIRM_BONUS` dict
- In `predict()`, call `vol_spike = _detect_volume_spike(df)` after the primary signal check
- Add vol_spike to the `confirms` list (append it after `_get_confirmations()` returns)
- Add a reason string when detected: `f"Volume spike: {vol_ratio:.1f}x average (capitulation confirmation)"`

**C. Update tests in tests/test_prediction.py:**
- Update any test that constructs mock data for `_detect_consec_down` to verify the new lower-close logic works
- Add a simple test for `_detect_volume_spike` with a DataFrame that has a clear volume spike on the last bar
